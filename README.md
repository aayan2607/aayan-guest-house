# Aayan Guest House

A welcoming and modern landing page for Aayan Guest House, designed to highlight the comfort, peace, and family-friendly atmosphere of the property.

## Overview

This project is a simple static website built using HTML and CSS. It presents a clean, stylish homepage with a hero image, welcoming description, and a call-to-action button that directs visitors to a Google search for the guest house.

## Features

- Elegant green-and-white theme
- Hero image section for visual appeal
- Clear description of the guest house experience
- Family-friendly branding
- Responsive layout for different screen sizes
- Simple call-to-action button

## How to Run

1. Download or clone the project.
2. Open `index.html` in your browser.
3. The website will load and display the landing page.
